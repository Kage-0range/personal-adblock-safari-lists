# personal-adblock-safari-lists

個人用の Safari 広告ブロッカーが読み込む、変換済みのコンテンツブロッカールールの配信先です。毎日自動で更新され、履歴は残しません。

元のフィルタリストは次のとおりです。各リストの権利は作者にあり、それぞれのライセンスに従います。

- [EasyList](https://easylist.to/easylist/easylist.txt)
- [EasyPrivacy](https://easylist.to/easylist/easyprivacy.txt)
- [EasyList Cookie List](https://secure.fanboy.co.nz/fanboy-cookiemonster.txt)
- [AdGuard Japanese filter](https://filters.adtidy.org/extension/safari/filters/7.txt)

変換には [SafariConverterLib](https://github.com/AdguardTeam/SafariConverterLib)（GPL-3.0）を使っています。
